will be given an image of diagram and you must describe it in a way that makes it easy for RAG systems
to score/interpret the diagram by reading your textual description of it. Cover objects and their
interactions with one another in detail. Return a JSON object with the description and keywords as
{"description": string, "keywords": string[]}, keywords must include organizations, projects, people and
other core entities/ideas in the visual content.

NOTE:
 - do not summarize the content, capture the idea of the figure, e.g. if it's a flowchart of data
   describe it in terms of data flow.
 - the diagram may be displayed inside an app like MicroSoft PowerPoint or presented in a conference call
   ignore everything else and focus solely on the diagram.
 - no meta commentary, nothing but the textual description of the diagram in the image.
 - include all metadata, like title, footnote, caption, anything relevant in the image.
 - if something is missing, do not output text explaining absence.
